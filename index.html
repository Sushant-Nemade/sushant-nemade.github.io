Security Checker

A local credential-screening CLI and browser scanner, with redacted findings and CLI SARIF output for GitHub code scanning.

TypeScript · SARIF · GitHub Actions integration

Repository
Case study

Configurable rules identify likely credentials without uploading source files. The CLI ignores dependency folders, symlinks, binary files and oversized inputs, and exports findings for code-scanning workflows.

Regex and entropy are screening signals, not a security guarantee. The browser UI scans selected text files only; directory recursion and SARIF export belong to the CLI. Confirm findings and revoke actual leaked credentials.

Subscription Auditor

Browser-local analysis of CSV and text-based PDF statements to estimate recurring monthly and annual payments without uploading financial files.

TypeScript · Next.js · CSV / PDF processing · Local-first design

Repository
Case study

Merchant normalization and recurring-interval detection keep statement processing on the device. Sample transactions support a public preview without personal financial data; the repository includes detector tests.

Scanned PDFs need OCR. Variable billing dates may be missed, and regular non-subscription payments can be false positives. Findings are estimates to review, not confirmed subscriptions or cancellation advice.
